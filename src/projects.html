Independent Game Project: Gasoline Alley

This project is a demo for a game that I've been conceptualizing since my time in university. Inspired by the classic Resident Evil games, players will find themselves stranded in a remote town deep in the mountains where the inhabitants have become a frenzied horde of blood-thirsty monsters. The gameplay centers around exploring the eerie locale and solving puzzles with the ultimate goal of finding a way to escape. Along the way, players will have to defend themselves from the town's residents, all while managing limited resources.

This project is being developed in Unreal Engine 5. It serves a dual purpose as both a creative outlet and as a means of educating myself on the various disciplines of game development. Incrementally building new features to realize my vision has let me dive into gameplay design, AI, and UI design, as well rigging and animation. Using UE5 I'm able to program primary in C++, while leveraging Unreal's visual scripting language, Blueprints, to more easily implement things like UI, NPC behaviour, and character animations.


The core mechanics are still being implemented. I hope to have a proof of concept demo in a shareable state soon!
